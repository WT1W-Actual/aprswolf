# APRSWolf v0.9

Release date:

- 2026-04-20

Primary download:

- `APRSWolf_0.9_universal.dmg`

## What's New

- Expanded received message filters with twelve filter categories for fine-grained traffic viewing.
- Auto-beacon on connect: when latitude, longitude, and symbol are configured, a position beacon is automatically sent when the TNC connects.
- Activity notice system: transient in-app notifications surface recent send and receive events in the main window without requiring the Traffic Log to be open.
- Received messages window can now be popped out into a separate window with full filter and reply support matching the main window.
- New in-app Help window with searchable user guidance and a macOS-style topic sidebar.
- Packet-level debug noise (TX DEBUG / RX DEBUG frames) is suppressed from the log display by default.
- Remote web control extended with full received message display, beacon controls, and improved status labels.

## User-Facing Changes

- New:
  Received message filter bar now includes twelve categories: All, To Me, Bulletins, Messages, Weather, Position, Status, Objects, Items, Mic-E, Telemetry, and Other. Multiple filters can be active at once.
- New:
  Auto-beacon on connect. When beacon coordinates and symbol are set, APRSWolf automatically sends a position beacon immediately after a TNC connection is established.
- New:
  Activity notice strip. A brief highlighted banner appears at the top of the sent/received area to echo recent TX and RX activity without requiring the Traffic Log to be open.
- New:
  Received messages window now supports pop-out to a separate window. The pop-out window has the same filter bar and click-to-reply support as the main pane.
- New:
  Help window. A built-in help view now provides guided setup, connection, receiving, beacon, remote control, and troubleshooting documentation without leaving the app.
- Improved:
  TX DEBUG and RX DEBUG packet-level events are no longer shown in the log; only meaningful status and error events appear.
- Improved:
  Remote web control page now includes the received message list, Mic-E badge display, and beacon section with the same behavior as the desktop app.

## Upgrade Notes

- Existing settings persist without modification.
- The auto-beacon feature is enabled by default when coordinates are present. If you do not want an automatic beacon on connect, clear the beacon latitude and longitude fields.
- The received message history from the prior session is cleared on each app start as established in earlier releases.
