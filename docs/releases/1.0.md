# APRSWolf v1.0

Release date:

- 2026-05-21

Primary download:

- `APRSWolf_1.0_universal.dmg`

Optional downloads:

- `APRSWolf_1.0_x64.dmg`
- `APRSWolf_1.0_aarch64.dmg`

## What's New

- First stable 1.0 release of APRSWolf for macOS.
- Consolidates the recent receive and messaging workflow improvements into a universal macOS release for Intel and Apple Silicon.
- Received message handling includes richer filtering, Mic-E decoding, a popped-out received window, and click-to-reply support.
- The desktop app includes in-app help, activity notices, clearer connection status labels, and automatic beaconing on connect when beacon coordinates are configured.
- Remote web control more closely matches the desktop experience with received-message display, beacon controls, stronger status labels, and saved-settings support.

## User-Facing Changes

- New:
  Received message filtering supports the current full category set: All, To Me, Bulletins, Messages, Weather, Position, Status, Objects, Items, Mic-E, Telemetry, and Other.
- New:
  Received messages can be popped out into a separate window with filter controls and reply actions that match the main app.
- New:
  Built-in help content is available directly in the app for setup, APRS-IS, TNC, beacon, remote control, and troubleshooting guidance.
- Improved:
  Mic-E packets decode into human-readable summaries when possible, and received views surface clearer message-type badges.
- Improved:
  TNC and APRS status areas use clearer labels and the app header now shows the release badge as `v1.0`.
- Improved:
  Remote web control includes received-message display, beacon controls, more explicit save/settings behavior, and closer feature parity with the desktop app.
- Fixed:
  Replying from the popped-out received messages window behaves the same way as replying from the main window.
- Improved:
  Packet-level TX/RX debug noise is suppressed from the log so only meaningful status and error events are shown by default.

## Upgrade Notes

- Existing settings remain compatible; no settings migration is expected for this stable release.
- If beacon latitude, longitude, and symbol are configured, APRSWolf automatically sends a position beacon when the TNC connects.
- Startup clears persisted received-message history and expires unresolved outbound queue entries from prior sessions.
- If you rely on cross-session queue retries, verify pending outbound items after upgrading and re-send anything you still need delivered.
