# APRSWolf v1.1.2

Release date:

- 2026-10-17

Primary downloads:

- `APRSWolf_1.1.2_x64.dmg` (Intel Mac)
- `APRSWolf_1.1.2_aarch64.dmg` (Apple Silicon Mac)

## What's New

- Outbound messages retry automatically until acknowledged or expired, with increasing backoff.
- Expired messages can be sent again from their context menu using the original message number.
- Remote Settings edits are protected from live traffic refreshes until saved.
- New-only CSV exports include later acknowledgements and completed multipart messages.
- The macOS app menu now includes the standard Hide, Hide Others, and Show All actions.

## User-Facing Changes

- Improved:
  Unacknowledged messages retry with delays starting at 15 seconds and doubling up to 4 minutes. After five send attempts without an ACK, the message expires.
- New:
  Right-click an expired sent message and choose `Resend`. It retains its original message number and is refused while that number is in use for the same station, or if the configured callsign differs from the original sender.
- Fixed:
  A later ACK or multipart completion is included in the next eligible new-only export.
- Improved:
  Remote Settings fields you've edited are not overwritten by incoming traffic. Save persists them, and edits made again while a save is in progress remain unsaved.
- Improved:
  Remote control inputs no longer trigger automatic zoom on iOS Safari.

## Upgrade Notes

- No settings migration or changed defaults are required for this release.
- Messages still awaiting an ACK when the app closes are marked expired at the next launch; use `Resend` to queue one again.

- macOS and Windows installers are not Developer ID signed or notarized and may require first-launch confirmation.
