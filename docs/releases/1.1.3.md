# APRSWolf v1.1.3

Release date:

- 2026-10-20

Primary downloads:

- `APRSWolf_1.1.3_x64.dmg` (Intel Mac)
- `APRSWolf_1.1.3_aarch64.dmg` (Apple Silicon Mac)

## What's New

- New `aprs.fi Map` and `aprs.fi Msgs` buttons in the Station row open your callsign on aprs.fi.
- Dependency security and maintenance updates for the Rust and npm toolchains.

## User-Facing Changes

- New:
  The Station row now has `aprs.fi Map` and `aprs.fi Msgs` buttons. They open your configured callsign (including SSID) on the aprs.fi map or the aprs.fi messages page in your default browser. Both buttons stay disabled until a callsign is set.
- Improved:
  Rust crates and npm packages were updated to current patch releases, including notification, XML, and Windows platform dependencies.

## Upgrade Notes

- No settings migration or changed defaults are required for this release.
- The aprs.fi buttons use your configured callsign; set it in Preferences if the buttons appear disabled.

## Known Issues

- macOS and Windows installers are not Developer ID signed or notarized and may require first-launch confirmation.
- The unread app icon count is platform-dependent; Linux support varies by desktop environment, and Windows displays a red dot rather than a number.
