# APRSWolf v1.0.3

Release date:

- 2026-10-12

Primary download:

- `APRSWolf_1.0_x64.dmg` (Intel Mac) or `APRSWolf_1.0_aarch64.dmg` (Apple Silicon Mac)

## What's New

- Fixes macOS reporting that APRSWolf "is damaged and can't be opened" after downloading v1.0.2 or earlier on an Apple Silicon Mac.

## User-Facing Changes

- Fixed:
  The macOS app bundle is now ad-hoc signed as a whole, so its signature is consistent with its contents. Previously the Apple Silicon build carried an incomplete linker signature, which Gatekeeper reports as "damaged" and for which it does not offer **Open Anyway**.

## Upgrade Notes

- No settings migration is required.
- The app is still not signed with an Apple Developer ID or notarized. On first launch macOS may still ask you to approve it: open System Settings → Privacy & Security and click **Open Anyway**.
- If you already installed an earlier build and see the "damaged" message, run `xattr -cr /Applications/APRSWolf.app` in Terminal, or install v1.0.3.

## Downloads

macOS:

- Intel DMG: `APRSWolf_1.0_x64.dmg`
- Apple Silicon DMG: `APRSWolf_1.0_aarch64.dmg`

Linux:

- Debian/Ubuntu (Intel/AMD 64-bit): `APRSWolf_1.0_amd64.deb`
- Debian/Ubuntu (ARM64, e.g. Raspberry Pi OS 64-bit): `APRSWolf_1.0_arm64.deb`
- Fedora/RHEL (Intel/AMD 64-bit): `APRSWolf-1.0-1.amd64.rpm`
- Fedora/RHEL (ARM64): `APRSWolf-1.0-1.arm64.rpm`
- AppImage (Intel/AMD 64-bit): `APRSWolf_1.0_amd64.AppImage`
- AppImage (ARM64): `APRSWolf_1.0_arm64.AppImage`

Windows:

- MSI installer (x64): `APRSWolf_1.0_x64.msi`
- NSIS installer (x64): `APRSWolf_1.0_x64-setup.exe`

Note: the macOS `aarch64` DMG is for Apple Silicon Macs. The Linux `arm64`
packages are for ARM64 Linux (for example a 64-bit Raspberry Pi). They are not
interchangeable.

## Known Issues

- macOS and Windows installers are not Developer ID signed or notarized and may require the first-launch confirmation described in the end-user guide.
