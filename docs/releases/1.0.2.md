# APRSWolf v1.0.2

Release date:

- 2026-10-12

Primary download:

- `APRSWolf_1.0_x64.dmg` (Intel Mac) or `APRSWolf_1.0_aarch64.dmg` (Apple Silicon Mac)

## What's New

- Preferences now show useful standard connection defaults instead of leaving those fields blank.
- The `Open Remote UI` button now opens the remote control page in the system browser from the desktop app.

## User-Facing Changes

- Improved:
  Blank standard settings now receive their defaults: TNC host `127.0.0.1`, port `8001`, and path `WIDE1-1,WIDE2-1`; APRS-IS server `rotate.aprs2.net` and port `14580`; Remote Web Control port `18420`.
- Fixed:
  `Open Remote UI` now opens the active remote page in the system browser. Browser preview continues to open the page in a new tab.
- Improved:
  Saving settings continues to preserve personal values such as callsign, passcode, beacon position, and remote token; those fields are not filled with defaults.

## Upgrade Notes

- No settings migration is required. Existing nonblank settings are preserved.
- Blank standard connection fields are filled with their defaults when settings load.
- The remote token remains empty by default, so Remote Web Control is limited to this computer unless you set a token.

Windows:

- MSI installer (x64): `APRSWolf_1.0_x64.msi`
- NSIS installer (x64): `APRSWolf_1.0_x64-setup.exe`

Note: the macOS `aarch64` DMG is for Apple Silicon Macs. The Linux `arm64`
packages are for ARM64 Linux (for example a 64-bit Raspberry Pi). They are not
interchangeable.
