# APRSWolf v1.1.1

Release date:

- 2026-10-13

Primary download:

- `APRSWolf_1.1.1_x64.dmg` (Intel Mac) or `APRSWolf_1.1.1_aarch64.dmg` (Apple Silicon Mac)

## What's New

- Export your message history to a CSV file, and import one back, from the File menu.
- A new About window shows the version, what APRSWolf works with, links, and credits.
- The remote web control page is rebuilt to match the desktop main window, and works on a phone.
- The README, user guide, in-app Help, and developer guide are brought up to date with all of the above.

## User-Facing Changes

- New:
  `File > Export Messages...` (Cmd/Ctrl+Shift+E) opens its own window and writes a CSV of your history. Left as it opens it exports the conversation — sent messages plus received messages, queries, and bulletins — oldest first, hidden ones included. Narrow it by direction, a date range, callsigns (a base call like `WT1W` matches every SSID), or `Only messages new since the last new-only export`. Positions, weather, and the other short-lived packets stay out unless you tick the box, which warns first that those are trimmed after the retention period. The file is UTF-8 with a BOM and CRLF line endings, every field quoted, and text a spreadsheet would run as a formula gets a leading apostrophe. The suggested name ends with the date and time, such as `aprswolf-messages-2026-10-13-143005.csv`.
- New:
  `File > Import Messages...` (Cmd/Ctrl+Shift+I) takes an export back in, including one you edited by hand. The whole file is checked before anything is written, and one bad row refuses the lot, naming up to ten of them. Rows already stored are skipped by UUID, or for a hand-added row with no UUID, by direction, sender, addressee, text, and time, so importing the same file twice does nothing. A sent message still marked queued or sent comes in as expired. Files over 50 MB, or not UTF-8, are refused. It is all one transaction, then every window reloads.
- New:
  `APRSWolf > About APRSWolf` now opens its own window instead of the native panel: logo, version, which TNCs it works with (any KISS/AGW TCP TNC, or APRS-IS with no radio), links to GitHub, the release notes, and Help, and credits. It follows the theme, and Escape or clicking a link closes it.
- Improved:
  The remote web control page is laid out like the desktop main window: a header with the version and the UTC and local clocks, the send row, then Sent and Received side by side with the same All, To Me, Messages, and Bulletins chips. Tap a received message and the send row fills in to reply. Acks stay hidden unless Show ACKs is on, same as the desktop. The bottom bar has Station, TNC, APRS-IS, and Remote, each with its status dot and its own buttons, following the desktop's rules for what is enabled when. Settings and the activity log fold away underneath. On a phone the panes stack.
- Improved:
  Lists now sort by message time instead of insertion order, so an imported message sits where its time puts it rather than at the top.
- Improved:
  The Help window's Close button lines up with the search box, and Escape closes Help.
- Fixed:
  The remote page's own APRS-IS passcode function was wrong (`N0CALL` came out `4066` instead of `13023`). It now matches the desktop's `deriveAprsIsPasscode()`.
- Fixed:
  Wrapped received messages no longer overlap each other on narrow screens.

## Upgrade Notes

- The message database schema migrates automatically by `user_version` (now 5). No manual action is required. Each migration step commits with its version bump, so a crash halfway leaves the database ready to retry.
- The new-only export mark is stored in the database. The first new-only export takes everything; the one right after it is empty.
- No settings changes and no changed defaults in this release.

- NSIS installer (x64): `APRSWolf_1.1.1_x64-setup.exe`

Note: the macOS `aarch64` DMG is for Apple Silicon Macs. The Linux `arm64`
packages are for ARM64 Linux (for example a 64-bit Raspberry Pi). They are not
interchangeable.

## Known Issues

- macOS and Windows installers are not Developer ID signed or notarized and may require the first-launch confirmation described in the end-user guide.
- The remote page has been checked on macOS at desktop and phone widths; it has not yet been tried on a physical phone.
- The unread app icon count has been tested on macOS only. Windows and Linux are covered by code review: Linux depends on the desktop environment (KDE Plasma and the Ubuntu dock show it; stock GNOME does not), and Windows shows a red dot overlay instead of a number.
