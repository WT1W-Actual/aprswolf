# APRSWolf v1.0.1

Release date:

- 2026-10-11

Primary download:

- `APRSWolf_1.0_universal.dmg`

## What's New

- Bug-fix release on top of v1.0.0. No new features; it fixes message delivery, a crash on malformed input, and remote-access security, and it removes duplicate lines from the Traffic Log.
- The README has been rewritten for new users, with a clearer quick-start and a screenshot.

## User-Facing Changes

- Fixed:
  The Traffic Log window no longer shows every status, delivery, and received line twice. Lines built from backend events are now shown once, and the "show ACKs" toggle hides acknowledgements completely.
- Fixed:
  Message delivery and acknowledgement handling is more robust. Reply/ack message IDs are parsed correctly, acks are matched to the right station, and the reply ack is appended at send time.
- Fixed:
  The app no longer panics on malformed or multi-byte input in ack parsing, received-message normalization, and status text handling.
- Fixed:
  Remote web control is safer. When no access token is configured it binds to loopback only, and cross-site requests and untrusted `Host` headers are rejected.
- Fixed:
  Uncompressed APRS weather reports are now classified as weather, and third-party wrapped packets are unwrapped using the inner payload.
- Improved:
  Settings are written atomically, so an interrupted save no longer leaves a partial or corrupt settings file behind.
- Improved:
  The README is rewritten for new users, with a quick-start, a feature overview, and a screenshot.

## Upgrade Notes

- No settings migration is required. Existing settings files load unchanged.
- If you use remote web control without an access token, it now listens on loopback only. Set a token if you need to reach it from another device.
- Verify your Traffic Log after updating: lines should appear once, and the "show ACKs" toggle should fully hide acknowledgements.
