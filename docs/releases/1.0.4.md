# APRSWolf v1.0.4

Release date:

- 2026-10-12

Primary download:

- `APRSWolf_1.0.4_x64.dmg` (Intel Mac) or `APRSWolf_1.0.4_aarch64.dmg` (Apple Silicon Mac)

## What's New

- Every download now carries the full version number in its filename, for example `APRSWolf_1.0.4_aarch64.dmg`. Earlier releases used a shortened `1.0`, so different releases had identical filenames.

## User-Facing Changes

- Changed:
  All macOS, Windows, and Linux release files are named with the complete `major.minor.patch` version.
- No functional changes to the app itself. It includes the v1.0.3 macOS fix for the "damaged and can't be opened" message.

## Upgrade Notes

- No settings migration is required.
- Filenames of releases v1.0.3 and earlier are unchanged.

## Downloads

macOS:

- Intel DMG: `APRSWolf_1.0.4_x64.dmg`
- Apple Silicon DMG: `APRSWolf_1.0.4_aarch64.dmg`

Linux:

- Debian/Ubuntu (Intel/AMD 64-bit): `APRSWolf_1.0.4_amd64.deb`
- Debian/Ubuntu (ARM64, e.g. Raspberry Pi OS 64-bit): `APRSWolf_1.0.4_arm64.deb`
- Fedora/RHEL (Intel/AMD 64-bit): `APRSWolf-1.0.4-1.amd64.rpm`
- Fedora/RHEL (ARM64): `APRSWolf-1.0.4-1.arm64.rpm`
- AppImage (Intel/AMD 64-bit): `APRSWolf_1.0.4_amd64.AppImage`
- AppImage (ARM64): `APRSWolf_1.0.4_arm64.AppImage`

Windows:

- MSI installer (x64): `APRSWolf_1.0.4_x64.msi`
- NSIS installer (x64): `APRSWolf_1.0.4_x64-setup.exe`

Note: the macOS `aarch64` DMG is for Apple Silicon Macs. The Linux `arm64`
packages are for ARM64 Linux (for example a 64-bit Raspberry Pi). They are not
interchangeable.

## Known Issues

- macOS and Windows installers are not Developer ID signed or notarized and may require the first-launch confirmation described in the end-user guide.
