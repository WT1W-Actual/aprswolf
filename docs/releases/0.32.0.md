## What's New

- Added a new macOS release workflow for Intel, Apple Silicon, and universal DMG packaging.
- Added dark mode and saved theme selection with `System`, `Light`, and `Dark` options.
- Added direct-message system sound alerts using the default macOS alert sound.

## User-Facing Changes

- New:
  Theme selection is now available in the main app and remote web UI.
- New:
  Direct messages addressed to your station can trigger a configurable macOS system sound.
- New:
  `Show ACKs` can hide APRS ACK traffic from the received-message view unless explicitly enabled.
- Improved:
  APRS inbound message display now strips trailing APRS message ID characters from visible message text.
- Improved:
  Remote Web Control now tracks the same saved settings as the desktop app for theme, ACK visibility, and message sound.
- Fixed:
  Message sound toggle is now visible in two places: in the Station settings (with clearer label "Play sound for direct inbound messages") and in the Received Messages header for quick access.
- Fixed:
  TNC disconnect is now idempotent—calling disconnect when already disconnected no longer throws an error.

## Upgrade Notes

- Existing settings files remain compatible; new settings default automatically when missing.
- `Message Sound` defaults to enabled.
- `Show ACKs` defaults to disabled.
- Theme defaults to `System`.
