## What's New

- Added backend Mic-E decoding support and visible Mic-E badges in received message views.
- Hardened TNC connection state handling to prevent half-connected/stuck states and improved TX/RX status labels.
- Improved dark mode control contrast and expanded remote web UI parity with desktop controls.
- Startup behavior now clears prior-session received messages and expires pending queue entries for a clean session start.

## User-Facing Changes

- New:
  Mic-E packets now decode into human-readable position/speed/course summaries when possible, with a Mic-E badge in received message lists.
- Improved:
  Top header now shows the current app version badge; TNC side status badges now show clearer labels (Connecting, Connected, Active, Error).
- Improved:
  Dark mode readability improvements for pop-out buttons and remote-control secondary button states.
- Fixed:
  Connection lifecycle now handles partial/failing TNC startup robustly and allows disconnect during in-progress connect attempts.
- Improved:
  Remote web control now includes explicit Save Settings, friendlier status labels, stronger control enable/disable gating, and received-message badges.

## Upgrade Notes

- Existing settings remain compatible and continue to persist between app launches.
- Startup now clears persisted received-message history and expires unresolved outbound queue entries.
- If you rely on cross-session queue retries, re-send pending messages after upgrading.
